# Changelog

All notable changes will be documented here. The project currently has no tagged release.

## Unreleased

### Added

- Safe paged/filterable row browsing, inline and form editing, optimistic concurrency, generated-key duplication, confirmed deletion, and CSV export.
- Structured database/table/column/index/foreign-key operations with SQL preview, metadata checks, and typed confirmation.
- Metadata relationship canvas with search, zoom, minimap, auto layout, persistent positions, FK proposals, snapshots, and JSON/SVG/PNG export.
- Query workspace with write confirmation, timeout, EXPLAIN, bounded results, export, and opt-in local history.
- Transactional CSV import, CSV/JSON table export, bounded SQL database backup/import, and explicit consistency limits.
- Live status/process administration, confirmed termination, accounts, effective grants, and scoped grant/revoke controls.
- Filterable server variables with capability-gated, allowlisted, strongly confirmed global changes.
- Definition browsing and server-specific Query editing for views, routines, triggers, and events, including direct event enable/disable.
- Database statistics and guarded schema/data copy, transactional bulk row deletion, keyset pagination, query tabs, snippets, formatting, search/replace, and metadata insertion.
- Verified isolated compatibility runs for MySQL 8.4.13 and MariaDB 11.4.5.
- Protected mutation audit logging that excludes request bodies, SQL text, credentials, tokens, and row values.
- Secure session-scoped MySQL/MariaDB connection flow with exact destination policy, remote TLS requirements, CSRF rotation, timeout handling, and attempt throttling.
- Server vendor/version/capability detection and a lazy, filterable, keyboard-navigable database metadata explorer.
- Safe connection dialog, redacted public session state, activity feedback, disconnect flow, and responsive connection-handshake workspace.
- Unit/integration/frontend coverage for credential redaction, route encoding, destination policy, rate limiting, CSRF, and disposable-engine metadata reads.
- Modular PHP 8.2+ runtime with normalized HTML/JSON responses and security headers.
- Public-only deployment layouts for Apache and Nginx, safe configuration template, and health endpoint.
- Responsive dark/light foundation workspace with accessible local layout controls and honest disconnected states.
- Explicitly gated fictional MySQL 8.4 and MariaDB 11.4 fixtures.
- PHPUnit, native Node test, PHP lint, database integration, and GitHub Actions foundations.
- Architecture, install, security, progress, feature matrix, and file-plan documentation.
